# What a board meets at boot and at rest (2026-09-24, the Phase 3 review's
# bench-risk findings, and Kevin's bench: "it sees about 0.05 mT when the
# probe is nowhere near"). (0) Zeros gone stale since the saved zero (0.05 on
# two TMAGs, 0.02 on three) with nothing near: the live readings are ADOPTED
# as the zero at boot - their difference from the saved zero is no dipole -
# and within two seconds the array reads nothing (the probe on the board at
# boot is bootprobe.txt). (c) Two zeros over the plain level with nothing
# there mid-session: no magnet within a minute (the half-minute hold, then
# the follow) and no presence flicker. (d) The MMC56x3 switched out: its
# zero holds under the probe. Runs with the bench's 1839 magnet.
# (The stale zeros first: a console command runs frames, and the board has
# its stale zeros from its first frame.)
@reference
@bias 0 0.05 0 0
@bias 3 0 -0.05 0
@bias 1 0.02 0 0
@bias 5 0 0.02 0
@bias 7 0 0 0.02
@seed 5
@strength 1839
:mmc off
:strength 1839
@run 1500
l
@expect "no magnet (strongest reading 0.0"
@seen "adopted as the zero at boot"
:load
@expect "presence toggled 0 times"
@bias 0 0 0 0
@bias 3 0 0 0
@bias 1 0 0 0
@bias 5 0 0 0
@bias 7 0 0 0
# (a minute: the adopted zeros read back as their negatives once the biases
# go, and are followed out with nothing present)
@run 60000

# (c) two zeros over the plain level, nothing there: two TMAGs read plainly,
# presence goes on, the fit is tried and refused (no dipole of the held
# strength fits two sensors' readings within the others' noise: chi, not
# the footprint), the readings are held the half-minute hold
# (MAG_OFFSET_HOLD_S) and followed out; within the minute the array reads
# nothing and presence has gone off. The cost of one such event: two
# toggles and some twenty refused cold starts. (Block (0)'s unwind above is
# the same event - the adopted zeros read back as their negatives once the
# biases go - so the count below is two events' worth.)
:load
@bias 2 0.05 0 0
@bias 3 0 0.05 0
@run 60000
l
@expect "no magnet"
:load
@expect "presence toggled 4 times"
@bias 2 0 0 0
@bias 3 0 0 0
@run 30000

# (d) the switched-out MMC's zero under the probe
@magnet row 15 3
@run 30000
@baselines
@seen "baselines over 0.02 mT: none"
@magnet off
@run 2000
