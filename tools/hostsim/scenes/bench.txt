# The bench as it is (2026-09-23): eight TMAG5273s, the MMC56x3 switched
# out, the probe's magnet 1839 mT*mm^3 (measured 2026-09-22). check.txt and
# strength.txt are the clean regression; this scene carries the bench's
# numbers, and each change to the estimator tightens the expectation it
# moves. `make check` runs it last.
:mmc off
@strength 1839
@seed 3
# The bench's errors: anisotropic noise (0.012 mT x/y, 0.006 z a frame,
# measured), two sensors' gains a few percent off (the datasheet's +/-5 %),
# two zero errors, and one sensor 1 mm from where the table says.
@noise 0.012 0.012 0.006
@gain 2 1.03
@gain 5 0.96
@bias 1 0.015 0 0
@bias 6 0 -0.012 0.008
@place 5 0.8 0.5 0

# The probe resting in row 15, hole 3: the counters the `d` stream lacks
# are on the :load report (presence toggles, frames missed while tracking,
# the strongest reading since the last look).
@magnet row 15 3
@run 3000
:load
@expect "presence toggled"
@expect "frames missed while tracking"
@expect "strongest reading since the last look"
@magnet off
@run 2000

# Reach map: the probe resting in the inner hole of rows 1, 5, 10, 15, 20,
# 25, 30 (with the 1839 magnet a TMAG5273 reads it plainly only within about
# 40 mm; the far corner of row 1 is 65 mm out). Per row: what `l` says.
# Before 2026-09-23 the board booted holding 4232 for this 1839 magnet, and
# rows 1 and 5 fitted WRONG (a basin off the end of the array, 25-29 %
# misfit, rough) until the learning caught up at row 10. Booting at the
# measured 1839 (MAGLOC_MAGNET_STRENGTH) they fix within a millimetre;
# the strength is then measured over 4 places 7 % low (1700: the gain and
# place errors bias it) and revised over 8; rows 10-30 fix, the bars
# widening toward row 30.
@magnet row 1 3
@run 3000
l
@expect "seen by 4+0 faint"
@expect "track: tracking"
:screen
@expect "row: 1 hole 3"
@magnet row 5 3
@run 3000
:screen
@expect "row: 4 hole 3"
# (as it is: a millimetre off along the board at the array's end - the world's gain and place errors; row 5 is the truth)
@magnet row 10 3
@run 3000
l
@expect "(held)"
:screen
@expect "row: 10 hole 3"
@magnet row 15 3
@run 3000
l
@expect "z 17."
:screen
@expect "row: 15 hole 3"
@magnet row 20 3
@run 3000
:screen
@expect "row: 20 hole 4"
# (as it is: one hole off across - the same errors; hole 3 is the truth)
@magnet row 25 3
@run 3000
:screen
@expect "row: 25 hole 3"
@magnet row 30 3
@run 3000
:screen
@expect "row: 30 hole 3"
@magnet off
@run 3000

# Rest: two minutes in row 15 hole 3; the counters over it: no cold start
# (3 since boot: the reach map's lifts and one too-few-noticing end between
# rows), no presence toggle, no run of misses, nothing dropped.
@magnet row 15 3
@run 1000
:load
@expect "3 cold starts since boot"
@expect "presence toggled 5 times"
@run 120000
:load
@expect "3 cold starts since boot"
@expect "presence toggled 5 times"
@expect "0 the misses run out"
l
@expect "track: tracking"
@expect "0 dropped, 0 restarts"
# ...and the settings' record says the held strength was MEASURED (1700:
# measured over 4 places at the array's end, where this world's gain and
# place errors bias it 8 % low, and not revised within 5 % since; a default
# is never written as if it had been measured).
s
@expect "strength=1700 measured"

# A 70 ms glitch on three sensors (the LED strip's data line into SDA, a
# corrupt read: the bus has no CRC) is ridden through from the last good
# place: frames missed, no track end, no cold start.
@bias 2 0.3 0.3 0.3
@bias 3 0.3 0.3 0.3
@bias 5 -0.3 0.3 0
@run 70
@bias 2 0 0 0
@bias 3 0 0 0
@bias 5 0 0 0
@run 500
:load
@expect "3 cold starts since boot"
@expect "0 the misses run out"
l
@expect "track: tracking"

# Hover: a minute 30 mm over row 15. As it is: the strongest reading sits at
# the presence level (0.04), the two stale zeros are a third of it, and the
# fit fails at a 41 % misfit against the 40 % limit: no cold start, but
# hundreds of frames missed (the outcome at the edge flips with a change
# of timing, so only the counters are expected).
@magnet row 15 3 30
@run 1000
:load
@expect "3 cold starts since boot"
@run 60000
:load
@expect "3 cold starts since boot"
@expect "frames missed while tracking"
l
# ...and lifted away from that ROUGH state, the far glow is gone within 1.2 s
# (the rough hold, MAGTRACK_ROUGH_HOLD_S: 2.5 s of a stale glow until 2026-09-23).
@magnet off
@run 1200
l
@expect "track: nothing"

# Absent: a minute with nothing there. As it is: no cold start, one presence
# toggle (the hover's end), the stale zeros drifting out.
@magnet off
@run 1000
:load
@expect "3 cold starts since boot"
@run 60000
:load
@expect "3 cold starts since boot"
@expect "presence toggled 6 times"
l
@expect "no magnet"

# Lift: the probe taken away; the track is gone within 1.2 s (a tracking
# track coasts 400 ms; a ROUGH one is held 2.5 s: the far glow).
@magnet row 15 3
@run 3000
@magnet off
@run 1200
l
@expect "track: nothing"

# The MMC56x3 clips at 3 mT: the probe touched down over it (the magnet 9 mm
# from the part) saturates it, and a saturated sensor is out of that frame.
:mmc on
@magnet 27.65 25.13 7 0 0 1
@run 500
m
@expect "SATURATED"
@magnet off
@run 1000
:mmc off
